# SecAssist 3

مساعد فحص أمني تفاعلي لـKali/Linux، بواجهة تيرمنل عربية/إنجليزية وDeepSeek API.
Python 3.10+ والمكتبة القياسية فقط؛ tmux اختياري للوحات المتجاورة.

## البداية

~~~bash
cd secassist
chmod +x secassist install_kali.sh
sudo ./install_kali.sh --core
./secassist --panes
~~~

داخل البرنامج:

~~~text
/setup
/scope add 192.0.2.10
/target 192.0.2.10
ابدأ باستطلاع بسيط، وضح الخطة وسبب كل أداة ثم اطلب موافقتي
~~~

192.0.2.10 عنوان توثيقي؛ استبدله بهدفك المصرح. لا حاجة لتحرير scope.txt.
يدعم /scope add عنوان IP، CIDR، نطاقًا، wildcard، أو URL.
تفويض URL يكون على مستوى المضيف، وليس المسار أو المنفذ.
*.example.test يشمل النطاق الأساسي وفروعه.
المفتاح يُدخل مخفيًا عبر /setup ويبقى في الذاكرة فقط، أو يقرأ من DEEPSEEK_API_KEY.
تُحفظ التفضيلات غير السرية تلقائيًا؛ /model يغيّر الموديل و/think يحدد جهد التفكير.
الافتراضي deepseek-flash؛ اختر موديلًا متاحًا لحسابك.
الأوامر المحلية وإدارة النطاق والتقارير تعمل دون مفتاح.

## أوضاع التنفيذ

| الأمر | السلوك |
|---|---|
| /mode explain | تحليل وشرح دون تشغيل أدوات نظام |
| /mode manual | اقتراح أمر لتنفذه بنفسك ثم تستورد النتيجة |
| /mode ask | موافقة لكل أمر؛ الافتراضي |
| /mode auto recon 30 20 | تفويض حتى recon لمدة 30 دقيقة و20 أمرًا |
| /mode auto active 30 20 | حتى active بنفس الحدود |
| /mode auto intrusive 15 10 | تفويض أوسع يتضمن intrusive؛ يتطلب كتابة grant |
| /mode ask | إلغاء التفويض للخطوات القادمة |
| /stop all | إلغاء التفويض وطلب إيقاف المهام وتوابعها |

التفويض محصور بالنطاق ومدة وعدد أوامر. تغيير النطاق/الهدف أو استئناف جلسة يعيد ask.
الخيارات خارج ملفات المعاملات المراجعة تحتاج تأكيدًا حتى مع التفويض.
الأوامر intrusive والتحذيرات تتطلب yes كاملة في الموافقة الفردية.
تعديل الأمر يعرضه ويطلب موافقة جديدة بعد التحقق. انتهاء التفويض لا يقطع مهمة بدأت قبله.

قبل أمر الموديل تظهر بطاقة: الملاحظة، الفرضية، سبب الأداة، النتيجة المتوقعة، وشرط التوقف.
أما /run فهو أمر منك ويُعرض بوضوح على هذا الأساس، دون اختلاق مبررات من الموديل.

## مشاهدة العمل

./secassist --panes يبدأ tmux بالمحادثة ولوحة حالة ولوحات مخرجات عند تشغيل الأدوات.
كبّر اللوحة بـCtrl+b ثم z، وتنقّل بـCtrl+b ثم o.
المخرجات مباشرة ومحفوظة؛ Enter يغلق لوحة المهمة المكتملة.
البرنامج يدير لوحاته فقط، ولا يقتل جلسات tmux الخاصة بك.

~~~text
/jobs
/watch JOB_ID
/stop JOB_ID
/parallel 2
/panes off
/panes on
~~~

بدون tmux استخدم /watch ID؛ Ctrl+C يرجع للمحادثة ولا يوقف المهمة؛ /stop للإيقاف.
المهام تعمل بالخلفية فتستطيع متابعة المحادثة وتغيير الوضع أثناء عملها.
في auto على تيرمنل Linux تفاعلي تُحلل النتائج المكتملة ويُستكمل العمل ضمن التفويض.
في ask أو الإدخال عبر pipe أو Windows، استخدم /continue أو /wait.
طلبات API متزامنة؛ Ctrl+C يرجع من انتظار الموديل، ثم /stop all عند الحاجة.
لا نسبة تقدم مختلقة: الحالة والمخرجات هي المؤشرات.

## المنهج والأدلة

ملاحظة ← فرضية ← اختبار ← تحليل ← تحديث الخطة.
التوجيهات تلزم الموديل بفصل الحقائق والاستنتاجات وتجنب التكرار وتفسير الفشل والتعارض؛
ليست ضمانًا لصحة الموديل أو أن كل اكتشاف ثغرة.

- /plan: أسئلة الفحص وحالاتها وأدلتها.
- /import PATH: تسجيل ملف محلي (حتى 16 MiB) دون API.
- /file PATH QUESTION: استيراده وإرساله للتحليل عبر API.
- /outputs: مصادر الأدلة.
- /findings: نتائج suspected أو user_confirmed.
- /confirm ID: تأكيد بشري بعد مراجعة الدليل؛ وجود الاقتباس لا يثبت الاستنتاج.
- /report: Markdown وJSON محليًا، بالأدلة والخطة وحدود التغطية وحالة التأكيد.
- /resume: سياق الهدف والخطة دون استرجاع الصلاحيات.
- /clear: مسح المحادثة مع إبقاء الأدلة.

لا تحفظ finding دون مصدر مسجل واقتباس مطابق؛ تُراجع بصمة الملف قبل حفظها.
الاستئناف يستخدم تاريخًا مقتبسًا غير موثوق، ولا يعيد تشغيل أوامر.
ملخصات القرارات مرئية، والتفكير الداخلي الخام لا يُعرض ولا يُحفظ على القرص.

## الأدوات

/tools يعرض المثبّت والناقص وحزم التثبيت، و/doctor يعرض العدد الفعلي.
التعريفات تشمل Nmap، curl، httpx، WhatWeb، Wafw00f، Subfinder، Amass، dnsx،
dig، host، nslookup، whois، ffuf، Gobuster، Feroxbuster، Dirsearch، Katana،
Arjun، Nuclei، Nikto، WPScan، SSLScan، testssl، ping، SNMPwalk، onesixtyone،
enum4linux-ng، smbclient، smbmap، rpcclient، NetExec، ldapsearch،
Impacket GetNPUsers/GetUserSPNs/lookupsid، SQLmap، Hydra، Searchsploit، hashid، TShark.

- sudo ./install_kali.sh --all يثبت الحزم المتاحة في Kali؛ الموديل لا يثبّت البرامج.
- دعم الأداة يعني تعريفها وتشغيلها المُدار، وليس مراجعة كل خياراتها أو التحقق من كل إصداراتها.
- ملفات معاملات مراجعة للأدوات الأساسية؛ الباقي يحتاج مراجعة بشرية.
- Nmap ينتج XML مُدارًا ومحللًا؛ البقية ترجع نصًا ويمكن اختيار JSONL عبر خياراتها.
- NSE مقيّد بأسماء تعريف محددة مع تأكيد، دون ملفات خارجية أو فئات عامة.
- Nuclei مصنف intrusive احتياطيًا؛ القوالب المثبتة جزء من سطح الثقة.
- TShark لتحليل capture مستورد داخل outputs فقط؛ لا التقاط حي.
- لا دمج مباشر مع Burp/ZAP؛ يمكن استيراد تقارير نصية منهما.

## حدود الأمان والخصوصية

التحقق من معاملات النطاق ليس sandbox أو عزل شبكة. الأدوات تعمل بصلاحيات مستخدمك،
وقد تستخدم DNS ومصادر عامة وإعداداتها الافتراضية. لا تثبيت لعناوين DNS أو جدار egress،
ولا ضمان أن أدوات الزحف أو القوالب لن تتصل بطرف آخر.
عند الحاجة لاحتواء شبكة فعلي استخدم مختبرًا/VM معزولًا وحسابًا عاديًا.
لا تشغّل المساعد كله بـsudo؛ تحتاجه لتثبيت الحزم فقط.

ملفات الأهداف والإعدادات وأعلام الإخراج الخارجية والمسارات التنفيذية المعروفة محظورة؛
الفحص محافظ وليس محللًا كاملًا لكل أداة. تحويلات curl التلقائية محظورة.
المحتوى المسترجع من الأدوات والملفات بيانات غير موثوقة، ولا يغير النطاق أو التفويض.

المحادثة والأدلة المختارة والملاحظات المسترجعة ترسل إلى endpoint المحدد.
لا تضع أسرارًا في arguments؛ تُحفظ في السجل المحلي.
تنقيح المفاتيح المعروفة وAuthorization مساعدة محدودة، وليس كشفًا عامًا للأسرار.
API keys لا تورث للأدوات. المخرجات النصية منقحة ومحدودة بـ16 MiB، وليست نسخة بايتية أصلية.

## الملفات والتطوير

البيانات في .secassist/ المستثنى من Git: scope.json وconfig.json وworkspace/لكل-هدف.
للأهداف outputs وevidence.json مع SHA256 وfindings.json وplan.json وsession.json
وaudit.jsonl وjobs.json والتقارير.
audit يحتفظ بسجل الجلسات؛ /jobs يعرض مهام العملية الحالية فقط.
نسخة واحدة لكل مجلد بيانات؛ لا تشغيل متزامن على نفس .secassist.
السجل قابل للتعديل وليس توقيعًا جنائيًا أو سجلًا مقاومًا للعبث.

~~~bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q core secassist.py
./secassist --version
~~~

الاختبارات بعمليات محلية غير ضارة دون فحص شبكة أو API حقيقي.
اختبار tmux يستخدم socket منفصلًا. راجع docs/VALIDATION.md لحدود التجربة.
اختر رخصة تناسب ملكية الكود قبل النشر العام؛ لم تُفترض رخصة.
المراجع في docs/RESEARCH.md.
